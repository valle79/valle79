## PROYECTOS DESTACADOS

### 🏡 Netland — Plataforma de gestión inmobiliaria

Sistema orientado a la gestión de operaciones inmobiliarias, con funcionalidades administrativas y herramientas para organizar la información de proyectos y clientes.

**Tecnologías utilizadas:** Python, FastAPI, React, TypeScript, PostgreSQL y SQLAlchemy.

- Desarrollo de funcionalidades frontend y backend.
- Integración con bases de datos relacionales.
- Organización de la aplicación para facilitar su mantenimiento y evolución.

[![Ver repositorio](https://img.shields.io/badge/Ver%20proyecto-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/valle79/web-netland)

### ⚙️ KARVATECH — Soluciones tecnológicas para el sector automotriz

Proyecto enfocado en el desarrollo de una plataforma web relacionada con servicios tecnológicos y gestión para el sector automotriz.

**Tecnologías utilizadas:** JavaScript, React, Python y Supabase.

- Desarrollo de interfaces web.
- Integración de servicios y datos.
- Trabajo con autenticación y configuración de servicios backend.

[![Ver repositorio](https://img.shields.io/badge/Ver%20proyecto-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/luisvc261190/karvatech-supabase)
